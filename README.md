## How it works

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` byte-for-byte into the output directory
(`$MAKEFUN_OUTPUT_DIR`, default `/output`). It first checks the PNG
magic bytes of the source, copies the file, then re-checks the magic
bytes of the copy and prints its size and SHA-256. No network, no
randomness, no timestamps — two runs write identical bytes.

Run it locally with:

```
MAKEFUN_OUTPUT_DIR=/tmp/ni21-out python3 main.py
```
